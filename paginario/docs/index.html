Sobre o projeto

Feito para aproximar pessoas e livros.

O Paginário é um projeto de biblioteca digital com catálogo de obras, pesquisa e páginas de detalhes. Esta página apresenta a experiência visual sem exigir instalação ou criação de conta.

⌘
Projeto de portfólioInterface responsiva inspirada em princípios de design minimalista, com atenção à legibilidade, navegação e acessibilidade. Para testar os recursos conectados ao MySQL, acesse a implantação PHP quando ela estiver publicada.
